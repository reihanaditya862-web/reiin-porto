# Reiin — Digital Playground

Website portofolio pribadi Reiin (Reihan Nor Aditya), mahasiswa Bisnis Digital PENS yang mengeksplorasi desain, teknologi, dan pengembangan produk digital.

## Isi

- `index.html` — satu file HTML mandiri (CSS dan script sudah tertanam, tanpa dependensi eksternal).

## Cara menjalankan

- Buka `index.html` langsung di browser, atau
- Lihat versi online jika GitHub Pages sudah diaktifkan.

Tautan sosial (Instagram, TikTok) dan tautan proyek (RecycleChain) membutuhkan koneksi internet.
